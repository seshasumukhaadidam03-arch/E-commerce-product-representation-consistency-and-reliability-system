# AI-Based E-Commerce Product Representation Consistency and Reliability Assessment System

A final-year B.Tech CSE major project that assesses whether e-commerce seller claims are consistent with customer review evidence.

## What This System Does
Takes a product listing (title, description, specifications, images) and customer reviews, then checks each seller claim against customer evidence to produce a reliability score.

## Project Structure
```
Major_Project/
├── data/sample/          # Sample product data for development and testing

├── app/                  # Streamlit web dashboard

```
